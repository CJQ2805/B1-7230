# DVC1124 20S APP Implementation Plan

## Goal

Port the APP AFE integration from DVC1117 to DVC1124 and configure the application for the new 20S battery, without changing the established APP task structure, low-power flow, CAN/UART packet layouts, Boot behavior, or log record format.

## Architecture

- Rename the chip-specific HSI AFE driver and its chip-specific exported symbols to DVC1124. Keep the neutral `hsi_afe_*` APP-facing API and existing `afe_task` scheduling.
- Configure both the APP cell limit and active AFE cell count to 20.
- Read DVC1124 cell-voltage registers using its contiguous two-byte cell map, starting at register `0x1D` with a two-byte step.
- Pack the DVC1124 24-bit balance register in its documented byte order, with only cell bits 0–19 allowed for this 20S product.
- Retain the current project’s I2C/CRC transport and verified board profile. Do not copy the GD7627 DVC1124 analog profile wholesale.
- Keep existing CAN/UART formats. Their 24-cell capacity remains; cells 17–20 become populated and cells 21–24 remain invalid/fill values.

## Tech Stack

- C firmware for N32G45x, Keil MDK project.
- Existing FreeRTOS 10 ms AFE task and software-I2C/CRC implementation.
- PowerShell source-contract test under `tool/tests` because no host C compiler or Keil command-line tools are available in this workspace environment.
- Hardware validation on the target board using Keil debug/watch windows and CAN/UART captures.

## Review Focus

1. Cell indexes 0, 15, 16, and 19 map to `0x1D`, `0x3B`, `0x3D`, and `0x43`; verify the register-address formula in the contract test and confirm live readings on hardware.
2. Balance bits 0, 15, 16, and 19 land in the correct DVC1124 CB bytes; source-contract checks cover byte order, and hardware validation confirms the four boundary cells independently.
3. No path reads or exposes cells beyond 20 as valid; the contract test checks the APP/AFE limits and 20-bit balance mask.
4. CAN and UART retain their existing frame/group layouts; cells 17–20 carry live values and 21–24 remain invalid/fill values. Verify using a 20S snapshot and captured frames.
5. The existing 10 ms AFE task does not publish stale or partial cell data as a complete sample; verify read-failure behavior, data-ready transitions, and task/stack margin on target.
